# claude-pipeline

Canonical source for the Claude Code multi-agent pipeline setup.

## What's here

```
commands/
  bootstrap.md        → install to ~/.claude/commands/bootstrap.md
  backlog.md          → install to ~/.claude/commands/backlog.md
  reformat-backlog.md → install to ~/.claude/commands/reformat-backlog.md

agent-pipeline-guide.html  — reference guide (also published as a Claude artifact)
```

Project-level files (`spec.md`, `build.md`, agent files) are generated by
`/bootstrap` inside each target repo — they're not stored here because they're
baked to a specific backend at generation time.

## Installing global commands

```bash
cp commands/bootstrap.md ~/.claude/commands/
cp commands/backlog.md ~/.claude/commands/
cp commands/reformat-backlog.md ~/.claude/commands/
```

Or just run `/bootstrap` in any repo — it installs the global commands
automatically if they're missing.

## Updating

Edit the command files here, commit, then re-copy to `~/.claude/commands/`.
`/bootstrap` won't overwrite global commands that already exist, so updates
are always manual.
